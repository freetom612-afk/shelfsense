# ShelfSense

אב-טיפוס סטטי (עברית, RTL, בלי build) של **ShelfSense**: פלטפורמה שמגדירה מראש תקציב ומאקרו, בונה תפריט שבועי מודולרי (Meal Prep, "שיטת הלגו") ומתרגמת אותו לסל קניות חכם ברשתות השיווק (רמי לוי / שופרסל), בלי בזבוז מזון ובלי עבודה ידנית.

**אתר חי:** https://freetom612-afk.github.io/shelfsense/

> זהו אב-טיפוס. המחירים, המוצרים והמתכונים הם נתוני דוגמה, ואין סליקה או הזמנה מקצה לקצה. הייצוא לסופר הוא סימולציה מקומית.

## מה יש באפליקציה

| דף | תפקיד |
|---|---|
| `index.html` | דף הבית: הצגת המוצר ושיטת הלגו |
| `onboarding.html` | אשף ב-4 צעדים: נתונים פיזיים, מטרה, תקציב (₪280 / ₪380 / ₪520), העדפות ורכיבים שנואים. מחשב יעד קלורי ומאקרו |
| `dashboard.html` | התפריט השבועי: 2 ארוחות עוגן, 2 ארוחות מהירות, ארוחת בוקר וארוחת גיבוי מהמזווה. "החלף מנה" (מנה שלמה, ±5% קלוריות ו-±10% חלבון) |
| `recipe.html` | מתכון מלא: מצרכים מפוצלים למתכלים ולמזווה, בחירת 1/3/5 מנות, שלבים עם טיימר |
| `low-calorie-recipes.html` | ספריית 10 מתכונים דלי קלוריות, עם סינון ומנות מותאמות לתפריט |
| `cart.html` | סל חכם: איחוד כמויות לאריזות, החלפת מותג של אותו מוצר, "יש לי בבית", השוואת רשתות, שכבת מזווה וייצוא עגלה |
| `reel.html` | Reel אנכי של 15 שניות |

## חוקי המוצר שמיושמים

- **שיטת הלגו:** 2 ארוחות עוגן (Batch Cooking), ארוחות מהירות (10–15 דק׳) וארוחת גיבוי ממוצרי מזווה.
- **החלפה בתפריט:** רק מנה שלמה, מאותו פרופיל תקציב, בטווח ±5% קלוריות ו-±10% חלבון.
- **החלפה בסל:** רק בין מק"טים/מותגים של אותו מוצר בדיוק.
- **שכבת מזווה:** מתכלים נכנסים לעגלה אוטומטית. מוצרי מזווה מסומנים "קיים בבית" וממתינים תחת "חסר לך משהו מהמזווה?".
- **Alpha:** הזרקת מק"טים לעגלת הרשת בלבד. התשלום מתבצע באתר הרשת.

## מבנה הפרויקט

```
index.html, onboarding.html, dashboard.html,
recipe.html, low-calorie-recipes.html, cart.html, reel.html
assets/
  data.js    מוצרים, מנות, ארוחות שבועיות, buildMenu / swapOptions / buildCart
  state.js   מצב משותף בין דפים (localStorage), data-ss="..."
  theme.js   ערכת העיצוב המשותפת (Tailwind) וסרגל ניווט תחתון במובייל
  img/       כל התמונות (מקומיות)
scripts/serve.ps1   שרת סטטי לפיתוח
CLAUDE.md, AGENTS.md, .agents/   הנחיות פרויקט ועיצוב
```

המקור לנתונים וללוגיקה הוא `assets/data.js` (`window.ShelfSenseData`). הדפים מציגים נתונים משם ומ-`assets/state.js` (`window.ShelfSense`) ולא מחזיקים עותק משלהם.

## הרצה מקומית

אין build. אפשר לפתוח את הקבצים ישירות בדפדפן, או להריץ שרת סטטי מקומי:

```bash
powershell -ExecutionPolicy Bypass -File scripts/serve.ps1 -Root . -Port 5517
```

ואז לגלוש ל-http://localhost:5517. Tailwind נטען מ-CDN, ולכן נדרש חיבור לאינטרנט בעת הטעינה.

## מצב ושמירה

הפרופיל, התפריט ובחירות הסל נשמרים ב-`localStorage` של הדפדפן (`shelfsense_profile`, `shelfsense_menu`, `shelfsense_cart`). אין שרת, ולכן הנתונים לא משותפים בין משתמשים או מכשירים.
